# Average Velocity on an Inclined Plane

Statistical analysis of repeated measurements of a cart moving down an inclined plane, including estimation of the mean velocity and its uncertainty, and comparison between the experimental result and an ideal kinematic prediction.

## Contents

- `analysis.py` — data processing and statistical analysis
- `report.tex` — LaTeX source of the lab report
- `report.pdf` — final report
- `figures/` — figures used in the report
