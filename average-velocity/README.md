# Average Velocity on an Inclined Plane

Statistical analysis of the average velocity of a cart moving on an inclined plane, including uncertainty estimation and comparison between measured and expected behavior.

## Contents

- `analysis.py` — data processing and statistical analysis
- `report.tex` — LaTeX source of the lab report
- `report.pdf` — final report
- `figures/` — figures used in the report
