# Damped Harmonic Oscillation Analysis

Analysis of a damped cart--spring oscillator using curve fitting and residual analysis to distinguish between sliding-friction and velocity-dependent drag models, estimate damping parameters, and compare experimental oscillation frequencies with theoretical predictions.

## Contents

- `analysis.py` — data processing, peak detection, curve fitting, residual analysis, and frequency estimation
- `report.tex` — LaTeX source of the lab report
- `report.pdf` — final report
- `figures/` — figures used in the report
